Study plan: Kubernetes from first principles to internals

Phase 1 — Foundations

Week 1 · Desired state, declarative APIs, reconciliation, architecture, and request lifecycle.



Phase 2 — Kubernetes The Hard Way

Weeks 2–3 · TLS, certificates, kubeconfig, etcd, control plane, worker nodes, networking.



Phase 3 — Component internals

Weeks 4–6 · API server, controllers, scheduler, kubelet, CRI, containerd, and Pod lifecycle.



Phase 4 — Advanced systems

Weeks 7–9 · Networking, storage, security, observability, failures, and troubleshooting.



Phase 5 — Source code and teaching

Weeks 10–12+ · Read selected Kubernetes source paths, run experiments, and develop original video lessons.
